One line: the funniest excuse an AI agent gives after failing a task.

> I handed your task to my background process, and it unionized on the spot.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

## Files

- `main.ts` — writes the excuse to `/output/entry.txt`, deterministic, no network.
